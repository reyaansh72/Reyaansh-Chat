## ✨ What’s inside

Reyaansh All-in-One Launcher is a modern Flutter app that started from chat and now delivers multiple mini apps in a single interface. It is designed to be a playful launcher experience with room to grow, so you can enjoy many useful tools without switching between separate apps.

## 🚀 Current release strategy

- ✅ **Android support ends at `v1.15`**
- 🌐 **Web builds are now the main release channel** and are hosted at **[Reyaansh-Chat.onrender.com](https://Reyaansh-Chat.onrender.com)**
- 🧪 **Desktop builds are in testing** on the `testing` branch
- 🎉 **Once testing completes, desktop will be released as a stable build**

## 🚀 Quick start

### For normal users
Visit the live web app at **https://Reyaansh-Chat.onrender.com** and enjoy the launcher directly in your browser.

### For developers
```bash
# Clone the repository
git clone https://github.com/reyaansh72/Reyaansh-Chat.git
cd Reyaansh-Chat

# Install dependencies
flutter pub get

# Run locally
flutter run
```

### For privacy-conscious users
You can run the app locally from the web build or from source, keeping your data on your own machine.

## 🛠️ Web build

```bash
flutter build web --release
```

> Note: Android CI builds are no longer active. The `testing` branch contains the latest desktop source build work.
